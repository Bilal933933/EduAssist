# مساعد النحو العربي — Gemini + RAG

مساعد ذكي يجيب عن أسئلة النحو العربي، مبني بنفس أسلوب `albayan-ai-tutor`:
**Gemini API كعقل + قاعدة معرفة متجهية (RAG) كمصدر موثوق للمعلومات.**

## الفكرة

```
سؤال الطالب
   ↓
1. يُحوَّل السؤال إلى متجه (Embedding)
   ↓
2. بحث دلالي في قاعدة المعرفة → أقوى 3 قطع تشابهاً
   ↓
3. تُدمج القطع في تعليمات النظام (System Prompt)
   ↓
4. Gemini يجيب معتمداً على المحتوى المسترجع
   ↓
إجابة دقيقة مبنية على المعرفة، لا على التخمين
```

## الهيكل

```
ai-grammar-tutor/
├── README.md                 # هذا التوثيق
├── requirements.txt          # المكتبات المطلوبة
├── .env.example              # قالب المتغيرات
├── .env                      # مفاتيحك الفعلية (لا تُرفع للمستودع)
├── data/
│   └── grammar_knowledge.md  # ★ قاعدة المعرفة: 13 باباً من قواعد النحو
├── store/                    # مخرجات الفهرسة (تتولد آلياً)
│   ├── chunks.json           # القطع المقسمة
│   └── vectors.npy           # المتجهات (768 بعداً لكل قطعة)
└── src/
    ├── indexer.py            # يحوّل المعرفة إلى قطع + متجهات ويخزنها
    ├── knowledge.py          # البحث الدلالي (KnowledgeBase)
    ├── chat.py               # بناء التعليمات واستدعاء Gemini
    └── main.py               # واجهة سطر الأوامر
```

## شرح الملفات والدوال

### `src/indexer.py` — محرك الفهرسة
- `load_chunks(path)`: يقرأ `grammar_knowledge.md` ويقسمه إلى قطع حسب العناوين `##` (كل باب = قطعة).
- `embed_texts(client, texts)`: يحول النصوص إلى متجهات عبر `gemini-embedding-001` (768 بُعداً).
- `index()`: يجمع القطع + المتجهات ويحفظها في مجلد `store/`.

### `src/knowledge.py` — قاعدة المعرفة
- `class KnowledgeBase`:
  - `__init__`: يحمّل القطع والمتجهات من `store/`.
  - `search(query_vector, top_k)`: يحسب تشابه جيب التمام بين السؤال وكل القطع ويعيد أقرب 3.

### `src/chat.py` — التحدث مع Gemini
- `build_prompt(question, hits)`: يبني تعليمات النظام + المحتوى المسترجع + السؤال.
- `ask(client, question, hits)`: يرسل الطلب إلى Gemini ويعيد الجواب.
- `embed_question(client, question)`: يحول سؤال الطالب إلى متجه للبحث.

### `src/main.py` — نقطة الدخول
- `main()`: يحمّل المفتاح وقاعدة المعرفة، ثم حلقة أسئلة وأجوبة تفاعلية تعرض القطع المسترجعة ودرجات تشابهها.

## التشغيل

```bash
# 1. تثبيت المكتبات
pip install -r requirements.txt

# 2. إعداد المفاتيح (انسخ .env.example إلى .env وضع مفاتيحك)
cp .env.example .env

# 3. فهرسة قاعدة المعرفة (مرة واحدة، أو بعد تعديل المعرفة)
python src/indexer.py

# 4. تشغيل المساعد
python src/main.py
```

## مثال حي

```
أنت: بماذا يرفع الفاعل؟
المعرفة المسترجعة:
  - [الجملة الفعلية] (تشابه 0.78)
  - [الأفعال] (تشابه 0.71)
  - [الجملة الاسمية] (تشابه 0.65)

المساعد: يرفع الفاعل بالضمة إذا كان مفرداً، وبالألف إذا كان مثنى،
         وبالواو إذا كان جمعاً.
```

## كيف تزيد المعرفة؟
أضف باباً جديداً في `data/grammar_knowledge.md` بصيغة:

```markdown
## اسم الباب الجديد
أول قاعدة في الباب.
ثانية قاعدة في الباب.
```

ثم أعد الفهرسة: `python src/indexer.py` — لا حاجة لتغيير أي كود.
